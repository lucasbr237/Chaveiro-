Coloque aqui os arquivos (baixe uma vez, com internet — veja README.md principal):

  inter-400.woff2
  inter-500.woff2
  inter-600.woff2
  inter-700.woff2
  material-symbols-outlined.woff2

Enquanto os arquivos não estiverem aqui, o app funciona normalmente usando a
fonte de sistema como fallback (definido em www/css/fonts.css) — só os ícones
Material Symbols não vão aparecer (viram texto/nada) até você baixar o woff2
correspondente.
